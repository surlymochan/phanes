# 组织诊断 Checker：dist 路径为普通文件而非目录时的错误处理
labels: p2,backend:codex
在 `openbot/examples/org-health-local/builder/check_site.py` 的 `check_site`（第 65-75 行）开头增加防御性目录判定：当传入的 `dist` 路径不存在或不是目录时（`not dist.is_dir()`），直接追加 `f"失败：站点路径不存在或不是目录：{dist}"` 并提前返回，避免后续遍历产生多余的子文件不存在报警；并在 `openbot/examples/org-health-local/builder/test_check_site.py` 中补充单元测试：传入普通文件作为 `dist` 参数运行 `check_site.py`，断言退出码非 0 且 stdout 明确包含该失败项。

验收：`python3 openbot/examples/org-health-local/builder/test_check_site.py`
