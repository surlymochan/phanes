# Issue bus 重启时取消信号完成当前 claim 后退出
labels: p1,backend:pi
通过可控 fake executor 在任务执行中触发 SIGTERM，验证 worker 不再领取第二张非空卡、等待当前执行结束、写回单一终态 result 后退出；executor 失败时仍写失败结果。不得依赖外部 GitHub。预计有效 diff ≥30 行。 文件：`openswarm/bin/openswarm`、`openswarm/tests/test_github_issue_bus.py`。

验收：`python3 -m unittest openswarm.tests.test_github_issue_bus`
