# Bus 评论乱序仍按时间判定结果归属
labels: p1,backend:pi
修改 `swrm/bin/swrm` 的 cmd_bus_run 与 bus_winning_claim，并扩展 `swrm/tests/test_bus.py`。当前 winner 按 created_at/id 选择，但结果扫描按响应列表切片，乱序响应会漏掉合法结果或纳入 claim 之前的结果。统一按 created_at/id 排序后再关联 claim 与后续结果；成功接受最早有效 claim 后的终态，失败场景中早于 claim 的结果不能终结 run，并最终走预算取消。用 fake gh 返回打乱的非空评论序列，覆盖同时间不同 id、合法成功结果与无有效后续结果。遵循 GitHub 评论协议，不引入租约。预计实现和回归共 40 行以上，约 30 分钟。

验收：`python3 -m unittest discover -s swrm/tests -p 'test_bus.py'`
