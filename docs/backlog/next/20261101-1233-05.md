# Issue Bus：claim 后任务 JSON 变更必须终止执行
labels: p1,backend:pi
在 `openswarm/bin/openswarm` 的 digest/claim 校验与 `openswarm/tests/test_github_issue_bus.py` 增加防竞态回归：worker 读取并校验 digest 后、执行前再次读取 issue；若任务 JSON 或 base 被修改，worker 必须撤销本次 claim、写入可分类失败结果且不得 checkout 或 push。非空任务未被修改时仍完成正常 claim→result 闭环，并保留原 digest。

验收：`python3 -m unittest openswarm.tests.test_github_issue_bus`
