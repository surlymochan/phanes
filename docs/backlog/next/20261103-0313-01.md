# E2E 无换行输出也限制诊断缓冲大小
labels: p1,backend:pi
修改 `examples/org-health-local/run_e2e.py` 的 forward_output 和 `examples/org-health-local/test_run_e2e.py`：当前 readline 遇到一条超长无换行输出会整条保留，单个 chunk 不受 CAPTURE_LIMIT 约束。改用有界读取并按字节裁剪尾部缓冲，保留实时输出转发和 UTF-8 可读性；成功子步骤的大量无换行输出应完整转发，失败子步骤的诊断只保留有界尾部与真实退出码。用真实子进程分别输出超过上限的 stdout/stderr，在末尾放唯一标记，验证成功与失败路径、缓冲长度和尾部标记，不能只修改提示文字。预计实现和回归共 40 行以上，约 30 分钟。

验收：`cd examples/org-health-local && python3 -m unittest test_run_e2e`
