# 组织诊断 DA：parse_periods 三种观察期间形态与错误分支纯单元测试
labels: p2,backend:codex
在 `openbot/examples/org-health-local/da/test_build_diagnosis.py` 增加针对 `openbot/examples/org-health-local/da/build_diagnosis.py` 的 `parse_periods`（第 141-187 行）的纯单元测试，直接 import 该模块调用函数，不启动子进程：

① `观察期间` 是对象且显式给出「起始期次/参考期次/截止期次」时，三个锚点与「数据截止」原样返回；没给「数据截止」时按 `last_day_of_month(end)` 推算。
② `观察期间` 是对象且只给 Boss 格式的「期次」列表时，按首个以「实际」结尾的项取起始、按观察月份对应的「实际」项取截止、按含「参考」的项取参考。
③ `观察期间` 是字符串时，按其中出现的 `YYYY-MM` 数量处理：3 个及以上取首个为起始、中间为参考、末个为截止；只有 1 个或 2 个时因缺参考期次抛 `BriefError`。
④ 错误分支：缺 `观察期间`、缺起始或截止期次、缺参考期次、期次不是 `YYYY-MM`、`数据截止` 不是 `YYYY-MM-DD`，都抛 `BriefError` 且信息里带对应字段名。

边界：只增加单测，不改 `parse_periods` 与 `build_diagnosis.py` 的实现；不依赖任何其它待办任务。
