# 组织诊断 校验器：结构定义含不支持关键字时给出可读错误
labels: p1,backend:pi
`openbot/examples/org-health-local/validate.py` 的 `Validator._check`（第 163-166 行）在遇到 `SUPPORTED_KEYWORDS` 之外的关键字时抛 `ValueError`，而 `main`（第 300-330 行）只在 `load_schema` 处捕获该异常，导致真正校验数据时抛出 traceback。请在 `main` 校验每个文件的阶段捕获这个 `ValueError`，把消息打到 stderr 并按「输入不可用」返回退出码 2（`EXIT_USAGE`），输出里不出现 traceback；同时在 `openbot/examples/org-health-local/test_validate.py` 增加用例：给 `--schema` 传一份含 `unevaluatedProperties` 的结构定义，断言退出码为 2、stderr 同时含「不支持的关键字」与该关键字名、stdout 与 stderr 都不含 `Traceback`。边界：不扩大 `SUPPORTED_KEYWORDS`、不改 `schema/diagnosis.schema.json`、不改校验通过（0）与校验失败（1）的判定与错误路径格式。

验收：`python3 openbot/examples/org-health-local/test_validate.py`
