# 组织诊断 Reviewer：核对快照期次键与任务书期次锚点
labels: p1,backend:pi
在 `openbot/examples/org-health-local/review/cross_check.py` 增加一个纯函数（放在 `check_period` 之后）：从快照 `metrics[*].数值` 收集期次键（全口径成本率的键去掉「整体」前缀），与任务书 `观察期间.期次`（Boss 格式）或起止/参考/截止锚点比对，键集合不一致时在现有「期间一致」检查项的 detail 里说明缺哪些键、多哪些键，不新增检查项；随后去掉 `openbot/examples/org-health-local/review/test_cross_check.py:255-266` 中 `test_brief_period_keys_mismatch_fails` 的 `unittest.expectedFailure` 标记。边界：只并入「期间一致」这一项，不改其余检查项语义、报告汇总计数口径（`共 N 项检查` 的条数保持不变）、CLI 退出码与 `--out` 报告格式。
