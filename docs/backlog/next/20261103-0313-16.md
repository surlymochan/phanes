# Bus worker 重启续发已完成但未上报的结果
labels: p1,backend:codex
修改 `swrm/bin/swrm` 的 cmd_bus_worker、bus_worker_run 与 `swrm/tests/test_bus.py`：worker 完成本地 run 后、发布结果评论前退出，issue 只有 claimed 标签，现有扫描只处理 queued 而遗留结果。为重启增加窄恢复路径：仅当最早有效 claim 的账号和 executor-name 均属于当前 worker，且本地同 run_id 有完整终态结果时，续做分支推送与结果评论发布；本地终态缺失或损坏时不重新执行任务，也不改变获胜 claim。已有合法结果评论时跳过续发。用两个进程阶段的临时 run 目录和 fake gh，验证恢复成功、无终态时不发布及已发布时不重复；断言执行器启动次数不增加。不引入租约过期重领，不涉及 SSH lane serve 恢复。预计实现和回归共 50 行以上，约 40 分钟。

验收：`python3 -m unittest discover -s swrm/tests -p 'test_bus.py'`
