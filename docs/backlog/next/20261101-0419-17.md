# OpenSwarm retro：retro_ratio 与 retro_peer_review_p1_ratio 纯单元测试
labels: p2,backend:codex
在 `openswarm/tests/test_retro.py` 中补充 `openswarm/bin/openswarm` 的 retro 统计纯单元测试：① `retro_ratio`: 空列表返回 `"— (0/0)"`，忽略非布尔值项，正确计算并通过百分比格式化输出；② `retro_peer_review_p1_ratio`: 过滤掉损坏或缺少必需字段的 peer_review 字典，统计 p0 > 0 或 p1 > 0 的记录数，忽略仅有 p2 的条目；③ `retro_exec_pass_ratio`: 统计布尔值占比并附带统计 `null` 计数；④ `retro_safe`: 测试转义 Markdown 特殊字符（如 `|`、反引号、`[`、`]`、`<`、`>`）及长度截断边界。纯内存运算，无网络调用。

验收：`python3 openswarm/tests/test_retro.py`
