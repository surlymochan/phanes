# Issue bus 常驻轮询遇到服务端恢复后继续消费
labels: p1,backend:pi
完善常驻 bus worker 的恢复契约：GitHub 先返回 503/429、随后恢复时，worker 在有界退避后继续 claim 后续非空 issue；连续失败达到阈值则退出且不重复 claim。使用 fake gh 调用真实 worker loop，检查调用序列、标签与结果评论。预计有效 diff ≥30 行。 文件：`openswarm/bin/openswarm`、`openswarm/tests/test_github_issue_bus.py`。

验收：`python3 -m unittest openswarm.tests.test_github_issue_bus`
