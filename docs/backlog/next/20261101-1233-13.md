# 组织诊断 Reviewer：交接文件缺少角色元数据时给出 findings
labels: p1,backend:agy
在 `openbot/examples/org-health-local/review/cross_check.py`、`review/test_cross_check.py` 与 e2e 调用处增加真实契约：brief、diagnosis、site summary 均有非空业务内容但缺少 producer/periods 元数据时，cross_check 应生成带文件路径和字段名的结构化 finding，并以失败退出；元数据齐全且数值一致时仍输出通过报告。禁止把缺字段当作空报告静默跳过。

验收：`python3 openbot/examples/org-health-local/review/test_cross_check.py`
