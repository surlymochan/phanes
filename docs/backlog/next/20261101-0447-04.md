# 组织诊断 DA：洞察里折算人头补当量单位
labels: p2,backend:codex
`openbot/examples/org-health-local/da/build_diagnosis.py` 的 `build_insights`（第 586-733 行）第二条洞察「整体折算人头 {start} → {end}」的内容写的是「整体折算人头由 10.4（2026-01）变为 12.4（2026-09）；年末测算 13.4（当量折算，非自然人数）」，起止两处数字没有单位，与任务书口径里「整体折算人头」的单位「人（当量）」不一致（`openbot/examples/org-health-local/boss/make_brief.py` 的 `build_definitions`），对应 `docs/reviews/org-health-data-consistency.md` 的 ISSUE-05。

改法：在该条洞察的内容里，给起止两处折算人头数值补上「人（当量）」单位（年末测算那处已有「当量折算」说明，可保持不变）。

边界：只补单位文案，不改数值、不改洞察条数与顺序、不改「类型」标注（事实/推断/边界）、不改其它洞察。

在 `openbot/examples/org-health-local/da/test_build_diagnosis.py` 增加用例：跑一次 `build_insights`（或直接读生成的快照），断言标题含「整体折算人头」的那条洞察内容里，起止数值后都带「人（当量）」。

验收：`python3 openbot/examples/org-health-local/da/test_build_diagnosis.py`
