# 简报生成器对重复期间行确定性去重
labels: p1,backend:codex
在 `openbot/examples/org-health-local/boss/make_brief.py` 与 `boss/test_make_brief.py` 中实现：面对非空输入中相同月份、相同指标的重复记录，明确按来源优先级确定一条并在简报中披露冲突；不同指标仍保留。使用临时 JSON 真正调用 CLI/函数，覆盖冲突与无冲突成功路径，预计≥30行。 相关契约位于 `data/diagnosis.json`。

验收：`cd openbot/examples/org-health-local && python3 -m unittest boss.test_make_brief`
