# Fleet harvest 空结果与失败结果不互相覆盖
labels: p2,backend:codex
明确 harvest 同时有成功、失败、无新结果主机时的清单契约：非空成功 bundle 保留，失败项带原因和 fetch_fails，空主机不制造伪 completed 项；下一轮成功后只收回一次。使用 fake fleet 真实调用 CLI，预计有效 diff ≥30 行。 文件：`openswarm/bin/openswarm-fleet`、`openswarm/tests/test_fleet.py`。

验收：`python3 -m unittest openswarm.tests.test_fleet`
