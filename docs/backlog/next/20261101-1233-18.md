# OpenSwarm bus：目标仓库基线不可达时在 claim 前失败
labels: p1,backend:codex
在 `openswarm/bin/openswarm` 的 github-issue dispatch/worker checkout 路径和 `openswarm/tests/test_github_issue_bus.py` 增加协议回归：task JSON 指向未被远端 branch/tag 广播的非空 base 时，planner/worker 应在 claim 或执行前报告 `base_unavailable`，不创建工作分支、不运行 verify；可达 base 仍完成正常 issue bus 闭环并记录 commit。

验收：`python3 -m unittest openswarm.tests.test_github_issue_bus`
