# 组织诊断 DA：原始目录含非 CSV 文件时忽略并保持快照
labels: p2,backend:pi
在 `openbot/examples/org-health-local/da/build_diagnosis.py` 与 `da/test_build_diagnosis.py` 增加回归用例：原始数据目录包含 README 或临时文本文件时，DA 仍只消费支持的 CSV，快照内容和排序保持稳定。若当前实现会把非 CSV 当数据处理，则做最小过滤修正；不要放宽必需 CSV 的缺失校验。

验收：`python3 openbot/examples/org-health-local/da/test_build_diagnosis.py`
