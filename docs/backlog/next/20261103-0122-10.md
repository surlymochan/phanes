# Org health serve 原子快照切换期间请求完整性
labels: p1,backend:codex
使用临时数据文件和真实 HTTP 请求，轮换两个含不同非空 metrics 的合法 diagnosis 快照；并发请求只允许返回完整旧版或新版 JSON，损坏替换窗口返回明确失败且恢复后继续服务。实现读取/校验策略并覆盖 HTTP 成功与失败，预计有效 diff ≥30 行。 文件：`openbot/examples/org-health-local/serve.py`、`openbot/examples/org-health-local/test_serve.py`。

验收：`python3 openbot/examples/org-health-local/test_serve.py`
