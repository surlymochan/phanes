# cross_check 对可定位 finding 做真实字段核验
labels: p1,backend:pi
在 `openbot/examples/org-health-local/review/cross_check.py` 与 `review/test_finding_paths.py` 中实现：解析 finding 路径并核对其引用的 diagnosis 字段和值，真实有效发现通过，伪造路径或不符值被标记为不一致；覆盖多条非空 finding。预计实现与测试≥30行。 相关契约位于 `review/test_cross_check.py`。

验收：`cd openbot/examples/org-health-local && python3 -m unittest review.test_finding_paths review.test_cross_check`
