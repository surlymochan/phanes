# Org health E2E 保留失败步骤前的有效产物
labels: p1,backend:agy
以真实 Boss/DA/Builder/Checker 子进程和临时目录执行非空合成数据：在 Checker 发现站点不一致时 E2E 以非零退出，保留 diagnosis 与 dist 供排查，timings 记录失败步骤和时长；再修正输入重跑成功且产物更新。预计有效 diff ≥30 行。 文件：`openbot/examples/org-health-local/run_e2e.py`、`openbot/examples/org-health-local/test_run_e2e.py`。
