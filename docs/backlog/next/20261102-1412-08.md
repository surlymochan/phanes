# org-health serve 请求期间客户端断开不终止服务
labels: p2,backend:pi

在 `openbot/examples/org-health-local/serve.py` 与 `test_serve.py` 验证真实 HTTP 行为：正常 GET 返回正确内容，客户端在响应中途断开时 handler 不使 server 线程退出，随后第二个请求仍得到 200；关闭服务后线程及时结束。若现有 handler 将 BrokenPipe 泄漏到服务生命周期，修正其边界处理。测试使用 loopback 临时端口和真实请求，不 mock handler。预计 30+ 有效实现/测试行，15–40 分钟。依据 `serve.py`、`test_serve.py` 及 `tests/test_serve_contract.py`。

验收：`python3 -m unittest openbot.examples.org-health-local.test_serve`
