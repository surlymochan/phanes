# Ready 队列读取隔离编码损坏卡片
labels: p2
修改 `tools/lane-autodispatch/autodispatch.py` 的 replenish 本地目录读取和 `tools/check-ad-ready-target.py`。现有 local_candidates 只在检查脚本内，AD 本地读取异常则提前 return，二者没有共用实现；把 local_candidates 提取到 AD，约定按文件名排序返回 (Path, text) 对列表，逐卡捕获 UnicodeDecodeError/OSError 并继续，过滤薄卡，由 replenish 复用，检查脚本通过 importlib 加载该真实函数。检查脚本必须用工作区临时目录放入排序靠前的无效 UTF-8 卡、薄卡及后续两张有效卡，直接调用 AD.local_candidates，断言仅两张有效卡按序返回，日志可定位坏卡；再以 fake gh/save_state/git 调用 replenish，断言两张有效卡成功派发、归档，坏卡未归档；全有效输入同样成功，不访问网络或真实控制面。编码异常未处理时上述验收必须失败，不得仅保留旧的镜像函数自测。预计实现和回归共 50 行以上，约 35 分钟。
