# serve API 支持条件请求并保持 HEAD 长度一致
labels: p2,backend:pi
在 `openbot/examples/org-health-local/serve.py` 与 `test_serve.py` 中实现：为诊断 API 实现 ETag/条件请求（或明确缓存策略），GET 与 HEAD 对非空诊断具有一致内容长度语义，匹配条件请求返回正确无体响应；通过本地临时 HTTP server 验证，预计≥30行。 相关契约位于 `test_serve_contract.py`。

验收：`cd openbot/examples/org-health-local && python3 -m unittest test_serve test_serve_contract`
