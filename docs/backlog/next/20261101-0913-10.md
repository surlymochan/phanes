# 组织诊断服务：根目录缺少诊断数据时返回可读错误
labels: p2,backend:agy
在 `openbot/examples/org-health-local/serve.py` 及其现有服务测试中补充 `--root` 指向存在但缺少 `data/diagnosis.json` 的静态目录用例，确认服务初始化或请求失败时返回非零/明确错误而不是 traceback；不得改变已有 `--root` 成功启动和端口边界行为。

验收：`python3 -m unittest discover -s openbot/examples/org-health-local -p 'test_serve.py'`
