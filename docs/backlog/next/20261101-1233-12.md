# 组织诊断 write_method：洞察引用的指标必须能回溯到快照
labels: p2,backend:codex
在 `openbot/examples/org-health-local/da/write_method.py`、`da/test_write_method.py` 与 `schema/diagnosis.schema.json` 建立来源契约：每条非空 insight/recommendation 的数字引用必须能在 facts/series 找到同值指标和 period，否则输出结构化错误；合法快照仍生成 Markdown，并保留问题回答与定义章节。用临时诊断 JSON 构造一个可回溯和一个伪造数字，跑真实命令检查成功/失败路径。

验收：`python3 openbot/examples/org-health-local/da/test_write_method.py`
