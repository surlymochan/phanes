# 诊断站点构建保持旧站点直到新产物完整
labels: p1,backend:agy
在 `openbot/examples/org-health-local/builder/build_site.py` 与 `builder/test_build_site.py` 中实现：构建采用临时输出并在 check_site 成功后原子替换；人为构造无效非空数据令检查失败时旧站点内容保持不变，正常新构建可替换。端到端使用临时目录，预计≥30行。 相关契约位于 `builder/check_site.py`。

验收：`cd openbot/examples/org-health-local && python3 -m unittest builder.test_build_site`
