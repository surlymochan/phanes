# OpenSwarm routing：routing_median 与 routing_tokens 纯单元测试
labels: p2,backend:codex
在 `openswarm/tests/test_routing_weights.py` 增加纯单元测试，覆盖 `openswarm/bin/openswarm` 的 `routing_median`（第 2084-2092 行）与 `routing_tokens`（第 2094-2105 行）：空列表返回 None；奇数个与偶数个数值的精确中位数；`routing_tokens` 分别提取 `entry["tokens"]["total"]`、`entry["tokens"]` 整数、`entry["usage"]["totalTokens"]` 以及 `attempts` 列表中尝试的 token 求和；未记录 token 时返回 None。纯数据运算，无外部依赖。

验收：`python3 openswarm/tests/test_routing_weights.py`
