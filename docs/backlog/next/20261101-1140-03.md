# SSH 证书续签前置检查的可执行实现
labels: p1
在 `docs/ctl-boot.md:11-22` 所指的 `ib-refresh`/控制面脚本中实现可测试的证书续签前置检查：读取临时 fleet 配置，区分仍有效、即将过期、已过期和缺失证书，续签失败时不替换旧配置，并输出机器可读结果供 boot 流程决定是否启动 lane-autodispatch。不得触碰真实凭据；用临时目录和 fake renew 命令覆盖非空 fleet 的成功、部分续签失败、重启后重复执行幂等路径。同步必要的脚本测试，不把工作落成文档-only。

验收：`python3 -m unittest discover -s openswarm/tests -p 'test_fleet*.py'`
