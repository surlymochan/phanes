# Fleet status 聚合保持离线主机的 lane 证据
labels: p2
针对非空多主机 inventory，某主机超时/非零退出时仍返回其他主机的 lane 状态，并将故障主机标为 failed、保留错误分类和汇总计数；下一轮恢复后状态更新为在线。通过 fake SSH 驱动 status JSON。预计有效 diff ≥30 行。 文件：`openswarm/bin/openswarm-fleet`、`openswarm/tests/test_fleet_render_lanes.py`。

验收：`python3 -m unittest openswarm.tests.test_fleet_render_lanes`
