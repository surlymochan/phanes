# 组织诊断 Checker：build-report.json 摘要解析的兼容与报错分支单测
labels: p2,backend:codex
`openbot/examples/org-health-local/builder/check_site.py` 的 `report_hashes`（第 50-73 行）声明兼容三种表示：`文件清单` 数组、`files` 字典、顶层 `sha256` 字典。现有 `openbot/examples/org-health-local/builder/test_check_site.py` 只覆盖了前两种，顶层 `sha256` 分支与几处报错分支没有单测。

请在该测试文件里补充用例（用临时目录构造 dist，不改 `check_site.py`）：

① 报告里只有顶层 `sha256`，形如「文件名 -> 64 位十六进制摘要」的扁平映射，站点检查通过、退出码 0。
② `files` 里直接放字符串摘要（不是 `{"sha256": ...}` 嵌套对象），站点检查通过。
③ `文件清单` 里某一项缺 `路径` 或缺 `sha256`，检查失败，stdout 出现「无法读取 build-report.json 中的 sha256」失败项，退出码非 0。
④ `files` 里有非字符串的键或非字符串的值，检查失败并同样报出上述失败项。
⑤ 报告里既没有 `文件清单` 也没有 `files`/`sha256`，检查失败并报出「build-report.json 缺少 files 或 sha256 对象」。

边界：只增加单测，不改 `builder/check_site.py` 的实现与输出格式；不依赖任何其它待办任务。

验收：`python3 openbot/examples/org-health-local/builder/test_check_site.py`
