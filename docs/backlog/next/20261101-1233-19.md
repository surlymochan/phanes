# OpenSwarm fleet：主机拓扑与 backend 白名单漂移时阻止自动派发
labels: p1,backend:pi
在 `openswarm/bin/openswarm-auto`、`openswarm/bin/openswarm-fleet` 和 `openswarm/tests/test_fleet_auto.py` 增加拓扑校验：配置中的 host 集合、lane 总容量和 backend 白名单与实际 snapshot 不一致时，自动派发返回结构化 drift 错误并不领取非空任务；一致且有匹配 backend 的 snapshot 仍能完成派发。测试用临时 policy 和 fake snapshot 覆盖多一个 host、容量不足、正常三种路径。

验收：`python3 -m unittest openswarm.tests.test_fleet_auto`
