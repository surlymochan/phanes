# E2E 超时清理仍存活的同组后代
labels: p1,backend:pi
修改 `examples/org-health-local/run_e2e.py` 与 `examples/org-health-local/test_run_e2e.py`：已有超时 killpg(SIGTERM) 只在组长 wait 再超时时升级 SIGKILL；组长快速退出而后代忽略 SIGTERM 时，后代仍会存活并持有管道。宽限期后检查并回收原进程组的残留成员，避免仅按组长状态判断清理完成。正常非空步骤成功；超时步骤用真实父进程派生忽略 SIGTERM 的子进程，父进程响应 SIGTERM 退出，断言最终失败且子进程退出、日志管道关闭；临时夹具必须有兜底清理。此卡仅处理本地 E2E 角色进程组。预计实现和回归共 45 行以上，约 35 分钟。

验收：`cd examples/org-health-local && python3 -m unittest test_run_e2e`
