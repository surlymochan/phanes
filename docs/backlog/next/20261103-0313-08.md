# 建站校验缺少资源时逐项失败
labels: p2,backend:codex
扩充 `examples/org-health-local/builder/check_site.py` 与 `examples/org-health-local/builder/test_check_site.py`，检查生成站点引用的脚本、样式和数据资源。全部资源存在时应通过；删除单项资源时应失败并指出具体引用，而不是只报泛化错误。通过临时站点执行校验命令，预计有效改动 35 行以上、约 20 分钟。
验收：`cd examples/org-health-local && python3 -m unittest builder.test_check_site`
