# DA 汇总对缺失期间与异常数值的稳健处理
labels: p1,backend:agy
构造非空多月收入、成本、汇率数据，覆盖一月缺失、汇率为零及非法数值：合法期间仍产出可消费 diagnosis，缺失/异常期间给出结构化错误且不产生误导性零值；CLI 的成功和失败均验证。预计有效 diff ≥30 行。 文件：`openbot/examples/org-health-local/da/build_diagnosis.py`、`openbot/examples/org-health-local/da/test_build_diagnosis.py`。

验收：`python3 -m unittest openbot.examples.org_health_local.da.test_build_diagnosis`
