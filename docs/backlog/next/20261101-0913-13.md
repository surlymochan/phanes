# OpenSwarm batch：零卡片输入生成稳定空汇总
labels: p2,backend:codex
在 `openswarm/bin/openswarm` 与 `openswarm/tests/test_batch.py` 增加空卡片、空结果和显式 base 的纯测试，确认不创建 runner、不访问 fleet，并输出既有 Markdown 汇总字段且数值为零/空集合。避开 #611 的空任务列表汇总语义，只覆盖 batch CLI 的空输入边界。

验收：`python3 -m unittest discover -s openswarm/tests -p 'test_batch.py'`
