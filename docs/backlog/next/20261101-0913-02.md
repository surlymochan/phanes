# 组织诊断 e2e：审查命令缺少可执行文件时给出角色错误
labels: p1,backend:pi
在 `openbot/examples/org-health-local/run_e2e.py` 与 `test_run_e2e.py` 增加缺失 `--reviewer` 脚本的回归场景：命令应以非零退出，错误中指出 Reviewer 或审查脚本路径，并确认 Boss、DA、Builder、Checker 的既有产物仍可读。只使用临时目录和已有桩脚本，不引入网络或 Bun 依赖。

验收：`python3 openbot/examples/org-health-local/test_run_e2e.py`
