# 组织诊断 Boss：--help 参数说明与 CLI 选项契约单测
labels: p2,backend:codex
在 `openbot/examples/org-health-local/boss/test_make_brief.py` 中补充 `boss/make_brief.py` 的 CLI 契约单元测试：① 运行 `make_brief.py --help` 退出码为 0，stdout 完整包含 `--out`、`--check`、`--goal`、`--month`、`--fx` 等选项说明及描述文案；② 不传 `--out` 且不传 `--check` 时进程非 0 退出，stderr 或 stdout 提示「必须指定 --out 或 --check」；③ `--month` 传入非法格式（如 `2026-9`、`2026-13`）时以状态码 2 退出，且提示必须是 YYYY-MM 格式。保持纯单测覆盖，不改动业务实现。
