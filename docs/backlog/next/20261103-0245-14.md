# E2E 临时工作区失败后清理并允许重跑
labels: p1,backend:codex
在 `openbot/examples/org-health-local/run_e2e.py` 与 `test_run_e2e.py` 中实现：当真实构建阶段失败，清理本次临时工作区的中间产物；修复输入后同一根目录再次执行能完整成功，不受残留锁或旧输出影响。覆盖失败后重跑与首次成功，预计≥30行。 相关契约位于 `builder/build_site.py`。

验收：`cd openbot/examples/org-health-local && python3 -m unittest test_run_e2e`
