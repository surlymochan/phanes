# Org health E2E 子进程超时后收割整组进程
labels: p1,backend:pi
让真实编排器支持每一步有界超时，并在子进程超时后终止其后代、记录步骤与耗时、保留此前成功产物；临时子脚本覆盖成功流水线与 DA 卡住失败，不得留下后台进程。预计有效 diff ≥30 行。 文件：`openbot/examples/org-health-local/run_e2e.py`、`openbot/examples/org-health-local/test_run_e2e.py`。

验收：`python3 openbot/examples/org-health-local/test_run_e2e.py`
