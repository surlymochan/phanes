# DA 多输入处理失败时不发布混合旧快照
labels: p1,backend:codex

修改 `openbot/examples/org-health-local/da/build_diagnosis.py` 和 `da/test_pipeline.py`，用两期非空 synthetic CSV 连续构建，第二期故意缺少必需列；成功期应产生与 period 对应的 diagnosis，失败期不得把上一期部分计算结果写成新快照，且下一次修复输入后可成功构建。覆盖 CLI 实际文件读写，不使用空输入模板。预计实现+测试 30+ 有效行，15–40 分钟。依据 `da/build_diagnosis.py`、`da/test_pipeline.py` 与 `run_e2e.py` 的阶段调用。
