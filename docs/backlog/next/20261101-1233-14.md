# 组织诊断 e2e：角色命令输出非 JSON 时保留原始诊断
labels: p1,backend:pi
在 `openbot/examples/org-health-local/run_e2e.py` 和 `test_run_e2e.py` 覆盖非空角色命令输出损坏 JSON 的路径：捕获 stdout/stderr 尾部、命令和退出码到步骤错误文件，已完成的 brief/diagnosis 仍可读取，最终结果不得伪造成功。另以真实角色脚本运行成功路径，确认正常 JSON 不被过度截断或误判。

验收：`python3 openbot/examples/org-health-local/test_run_e2e.py`
