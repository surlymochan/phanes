# OpenSwarm routing：routing_outcome 与 outcome_label 纯单元测试
labels: p2,backend:codex
在 `openswarm/tests/test_routing_weights.py` 中补充 `openswarm/bin/openswarm` 的路由结果辅助函数纯单元测试：① `routing_outcome(entry)`: 当 `entry` 包含布尔值 `accepted` 时直接返回 `accepted`；当 `accepted` 为非布尔值而 `exec_pass` 为布尔值时返回 `exec_pass`；二者均非布尔值时返回 None；② `routing_passed(entry)`: 当且仅当 `routing_outcome(entry) is True` 时返回 True；③ `outcome_label(entry)`: 结果为 True 返回 `"pass"`，为 False 返回 `f"fail/{status}"`，为 None 返回 `"unknown"`。只用标准库单测，不依赖外部进程。

验收：`python3 openswarm/tests/test_routing_weights.py`
