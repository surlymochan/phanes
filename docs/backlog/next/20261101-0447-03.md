# 组织诊断 DA：问答回答全口径期次覆盖与缺口呈现
labels: p2,backend:codex
`openbot/examples/org-health-local/da/build_diagnosis.py` 的 `answer_question`（第 736-772 行）对必答问题「全口径技术成本率（含运维与设施）在哪些期次有同口径值？缺同口径值的期次如何呈现？」只是复读三个成本率，没有回答该问题关心的期次覆盖与缺口呈现（`docs/reviews/org-health-data-consistency.md` 的 ISSUE-04）。

改法：在 `answer_question` 里新增一个早于现有「率」分支的判断——问题含「全口径」或「同口径」时，回答里写明两类期次：① 有同口径值的期次（`facts["ratios"]["full"]` 中取值非 `None` 的项，用 `facts["labels"]` 里的期次键名，如 `2026-01实际`、`2026-09实际`）；② 缺同口径值、按 `null` 呈现（界面显示为未提供）的期次。

边界：只新增这一条分支，不改现有分支顺序与文案、不改 `facts` 结构、不改快照输出结构。

在 `openbot/examples/org-health-local/da/test_build_diagnosis.py` 增加用例：构造 `facts`（`labels` 含 start/reference/end/forecast，`ratios["full"]` 里 reference 与 forecast 为 `None`）后调用 `answer_question`，断言返回内容里出现有值的期次名、出现 `null` 或「未提供」的缺口表述，且不含其它期次的数值。

验收：`python3 openbot/examples/org-health-local/da/test_build_diagnosis.py`
