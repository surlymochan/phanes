# 批次收割保留远端分支清理失败的交付
labels: p1,backend:pi
修改 `swrm/bin/swrm` 的 batch_collect 及其调用处，并扩展 `swrm/tests/test_batch.py`：当前 transfer_ref 成功且提交一致后，远端 branch -D 失败仍抛异常，已收割结果被当成整体失败。将传输和清理结果分开，成功传输的非空分支应保留真实 commit/status/verify_rc；清理失败记录 cleanup_pending 与主机、分支供后续重试，不丢失已收割交付。用临时 git 仓库和 fake host_require 验证清理成功、仅删除失败两条路径；提交不一致的失败仍必须阻止交付，不能吞掉传输异常。预计实现和回归共 45 行以上，约 35 分钟。

验收：`python3 -m unittest discover -s swrm/tests -p 'test_batch.py'`
