# OpenSwarm review：代码围栏内的 JSON 包装响应可解析
labels: p2,backend:codex
在 `openswarm/bin/openswarm` 与 `openswarm/tests/test_review.py` 增加评审响应被 Markdown json 围栏包裹、前后有空白的纯单元用例，确认能提取 findings schema；围栏未闭合或含多个冲突 JSON 时仍拒绝并保留可审计原文。不要改必填字段错误语义（#557）。

验收：`python3 -m unittest discover -s openswarm/tests -p 'test_review.py'`
