# 数据定义面板与计算输出使用同一指标键
labels: p2,backend:pi
在 `openbot/examples/org-health-local/test_data_definitions.py` 与 `app.js` 中实现：建立可执行契约校验，覆盖真实诊断输出中的指标键、单位和定义映射；未知指标在生成站点时显式失败，已知非空指标通过。校验须调用实际构建链路，预计≥30行。 相关契约位于 `data/diagnosis.json`。

验收：`cd openbot/examples/org-health-local && python3 -m unittest test_data_definitions`
