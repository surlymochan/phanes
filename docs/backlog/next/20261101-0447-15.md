# OpenSwarm lessons：根因分类与标题清洗辅助函数纯单元测试
labels: p2,backend:codex
在 `openswarm/tests/test_lessons.py` 增加针对 `openswarm/bin/openswarm` 的四个纯函数的单元测试（不读文件、不联网）：

① `lesson_root_cause_class`（第 927-932 行）：文本含 `token`/`credential`/`secret` 时归类为 `secret_exposure`；含 `race condition`/`deadlock` 时归类为 `concurrency`；含 `missing tests`/`untested` 时归类为 `missing_test`；含 `trust boundary`/`sandbox` 时归类为 `trust_boundary`；无关文本与空串都归类为 `other`。
② `lesson_plain_text`（第 959-970 行）：去掉 markdown 强调（`**`、`__`、`~~`、反引号）；`[文本](链接)` 只留「文本」；HTML 标签被去掉；`P1 Badge` 之类的徽标图片与文字徽标被剔除；多余空白合并成一个空格。
③ `lesson_finding_title`（第 935-957 行）：多行评论里取第一行有内容的标题；`[P1] xxx`、`P1: xxx`、`P1 — xxx` 这类前缀被剥掉；只有徽标的行（如 `P1 Badge`）被跳过；没有可用标题时返回 `Review the affected code path`；结果里的凭据串会被脱敏。
④ `lesson_rule_sentence`（第 972-976 行）：输出以 `Prevent recurrence of this finding:` 开头、以 `.` 结尾，标题里的 `.`/`!`/`?` 被换成 `;`，只保留一句。

边界：只增加单测，不改 `openswarm/bin/openswarm`；与已单独立项的 `lesson_proposal_yaml` 序列化测试无关，不依赖任何其它待办任务。

验收：`python3 openswarm/tests/test_lessons.py`
