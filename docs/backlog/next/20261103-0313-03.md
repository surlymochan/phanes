# Brief 检查模式同样核对诊断期次
labels: p2,backend:agy
修改 `examples/org-health-local/boss/make_brief.py` 与 `examples/org-health-local/boss/test_make_brief.py`：当前 --diagnosis 只在生成路径参与 check_periods_alignment，--check 会提前返回而忽略它。让检查已有 brief 时也加载给定诊断并执行同一套期次对账；非空匹配输入成功，brief 本身合法但 diagnosis 期次不一致时失败，损坏诊断也非零退出，--check 不带 --diagnosis 保持既有行为。通过临时文件真实调用 CLI，断言退出码、对账结果和两份输入字节均未改变。预计有效改动 35 行以上，约 25 分钟。

验收：`cd examples/org-health-local && python3 -m unittest boss.test_make_brief`
