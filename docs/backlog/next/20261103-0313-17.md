# 常驻 Bus worker 隔离单条 issue 读取故障
labels: p2,backend:pi
修改 `swrm/bin/swrm` 的 cmd_bus_worker 与 `swrm/tests/test_bus.py`：扫描中一条 issue 的评论读取抛 BusError 时，当前异常结束整个常驻循环。按 issue 捕获读取和处理异常，记录 issue 编号后继续本轮后续 issue；全正常时成功处理非空任务，首条评论 API 失败时后续正常任务仍成功且故障条目留待下轮。--once 应扫描完本轮可用条目或处理一条成功任务后退出，不因坏条目提前结束。用 fake gh 返回两条完整任务并注入首条读取故障，断言第二条真实进入 worker 流程和下一轮恢复，不改变 claim 归属。预计有效改动 40 行以上，约 30 分钟。

验收：`python3 -m unittest discover -s swrm/tests -p 'test_bus.py'`
