# OpenSwarm watch：缺少 lane 字段的事件不破坏心跳快照
labels: p2,backend:codex
在 `openswarm/bin/openswarm` 与 `openswarm/tests/test_watch.py` 增加事件字段不完整但含合法 assistant 文本的用例，确认 watch 保留文本、生成可序列化快照并只跳过无法归属的字段；不得重复修改未知事件过滤（#608）。测试必须是内存事件，不启动 daemon。

验收：`python3 -m unittest discover -s openswarm/tests -p 'test_watch.py'`
