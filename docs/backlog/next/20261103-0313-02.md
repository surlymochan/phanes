# 静态站构建拒绝路径逃逸
labels: p1,backend:codex
在 `examples/org-health-local/builder/build_site.py` 和 `examples/org-health-local/builder/test_build_site.py` 为复制资源增加目标根目录约束。合法嵌套资源应成功生成，包含 `../` 的输入应明确失败且不得改写临时站点之外的文件；用临时目录执行完整构建回归。预计实现和回归共 40 行以上，约 30 分钟。
验收：`cd examples/org-health-local && python3 -m unittest builder.test_build_site`
