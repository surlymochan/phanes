# 组织诊断 Reviewer：隐私边界黑名单词条深度嵌套与复合字段覆盖测试
labels: p2,backend:codex
在 `openbot/examples/org-health-local/review/test_cross_check.py` 增加用例，覆盖 `forbidden_paths` 对深层嵌套字段与复合命名的拦截逻辑：断言当敏感黑名单词条（如 `岗位`、`工号`、`绩效`、`职级`、`薪酬`、`编制`）出现在 `metrics` 嵌套指标序列或 `recommendations` 内部对象属性时，审查结果明确判为 FAIL 并打印对应键名路径；同时验证如 `整体折算人头`、`营收业务技术人力成本` 等合法聚合指标不会被误报。

验收：`python3 openbot/examples/org-health-local/review/test_cross_check.py`
