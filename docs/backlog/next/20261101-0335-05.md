# 组织诊断 校验器：CLI 退出码 2 与 --json 错误条目
labels: p2,backend:codex
在 `openbot/examples/org-health-local/test_validate.py` 增加 CLI 回归用例：①待校验文件不存在时退出码为 2（输入不可读，见 `validate.py:28-31`），stderr 提示里含该路径；②待校验文件是损坏 JSON 时退出码为 2，错误消息含「第 N 行第 M 列」；③同样两种输入加 `--json` 时 stdout 仍是可被 `json.loads` 解析的单个 JSON 对象，`ok` 为 false、`errors` 列表里含 `path` 与 `message`，且 stdout 不混入非 JSON 文本。只补测试，不改 `validate.py` 的退出码契约（0 通过 / 1 校验失败 / 2 输入不可读）与错误文案，也不改结构定义文件。

验收：`python3 openbot/examples/org-health-local/test_validate.py`
