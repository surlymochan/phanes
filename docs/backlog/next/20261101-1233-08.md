# 组织诊断 serve：静态资源异常不吞掉 API 响应
labels: p2,backend:agy
在 `openbot/examples/org-health-local/serve.py`、`test_serve.py` 增加真实 HTTP 回归：静态 `index.html` 缺失或读取失败时，`/api/diagnosis` 仍返回有效 JSON 和正确 Content-Type，静态路径返回可读 404；正常非空 diagnosis 数据下页面与 API 都保持成功。测试用临时 root 启动 `ThreadingHTTPServer`，不要只调用 handler 的空输入单元函数。

验收：`python3 openbot/examples/org-health-local/test_serve.py`
