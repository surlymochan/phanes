# Bus 常驻轮询临时 API 错误恢复后继续 claim
labels: p1,backend:codex

修改 `openswarm/bus.py` 与 `openswarm/tests/test_bus.py`，以确定性 fake API 序列运行常驻 worker：queued issue 被处理后遇到短暂 429/5xx，按 capped backoff 重试并在服务恢复后领取下一项；连续失败达到配置上限时以明确状态退出且不重复 claim 已完成任务。断言 poll 次数、退避值、结果条数，使用非空 issue 数据。预计实现+测试 30+ 有效行，15–40 分钟。依据 `openswarm/docs/BUS.md` 常驻 loop 说明。

验收：`python3 -m pytest openswarm/tests/test_bus.py -q`
