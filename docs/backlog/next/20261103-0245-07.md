# 简报字段映射保留数值零而非当作缺失
labels: p1,backend:agy
在 `openbot/examples/org-health-local/boss/make_brief.py` 与 `boss/test_make_brief.py` 中实现：修复简报构造中使用 truthy 默认值导致 0 收入/零风险被替换为空的情况；非零值照常生成。用包含多项非空指标及零值的临时诊断数据验证输出 JSON/schema，预计≥30行。 相关契约位于 `boss/brief.schema.json`。

验收：`cd openbot/examples/org-health-local && python3 -m unittest boss.test_make_brief`
