# 组织诊断 Builder：静态文件复制异常时的清理与退出码测试
labels: p2,backend:codex
`openbot/examples/org-health-local/builder/build_site.py` 的 `main`（第 168-182 行）在 `build_site` 抛出 `OSError` 时，若输出目录是本次新创建的（`created = True`），会调用 `shutil.rmtree` 并在 stderr 打印「构建失败」后返回退出码 3（`EXIT_BUILD`）。请在 `openbot/examples/org-health-local/builder/test_build_site.py` 补充单元测试：通过 mock `copy_static_files` 抛出 `OSError("Simulated disk error")`，断言 CLI 退出码为 3，stderr 包含「构建失败」与错误原因，且新建的半成品目录被正确清理。只补测试，不改实现。
