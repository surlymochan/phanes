# 组织诊断 Builder：build_site.py --help 与缺失必需参数的命令行测试
labels: p2,backend:codex
在 `openbot/examples/org-health-local/builder/test_build_site.py` 补充 CLI 参数契约回归用例：① 运行 `python3 build_site.py --help` 退出码为 0，stdout 包含 `--data`、`--out` 与 `--bundle` 的参数说明；② 命令行缺少 `--data` 或缺少 `--out` 时报错退出，退出码非 0 且 stderr 提示缺少必需参数；③ 当 `--out` 指定的多级深层父目录尚不存在时，构建能自动创建各层级目录并生成合规站点。只用临时目录与现有最小夹具，不改动 `build_site.py` 核心实现。

验收：`python3 openbot/examples/org-health-local/builder/test_build_site.py`
