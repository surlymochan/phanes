# CSV 管线报告逐文件解析统计
labels: p2,backend:codex
在 `openbot/examples/org-health-local/da/build_diagnosis.py` 与 `da/test_pipeline.py` 中实现：产出数据摘要记录各输入 CSV 行数、期间范围和被排除行数，并在成功诊断中可追溯；有效非空多期数据通过，夹杂格式错误行时按既定策略计数。用临时 CSV 调用真实管线，预计≥30行。 相关契约位于 `da/sample-raw/revenue.csv`。

验收：`cd openbot/examples/org-health-local && python3 -m unittest da.test_pipeline`
