# 组织诊断 e2e：自定义原始数据路径的帮助文案
labels: p2,backend:agy
在 `openbot/examples/org-health-local/run_e2e.py` 的 argparse 帮助与 `test_run_e2e.py` 中补齐 `--raw`、`--bundle`、`--workdir` 的用途说明，明确路径相对当前工作目录解析；不得改变参数默认值、转发参数或已有退出码。增加一个直接调用 `--help` 的断言，确保三项参数都出现在帮助中。

验收：`python3 openbot/examples/org-health-local/test_run_e2e.py`
