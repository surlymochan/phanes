# OpenSwarm route：未知任务类型保持可路由的默认决策
labels: p2,backend:codex
在 `openswarm/bin/openswarm` 与 `openswarm/tests/test_route.py` 增加未知或空 `type` 的纯函数用例，确认不会抛异常，并落入现有稳定默认难度/后端桶；同时断言显式 backend/model 仍优先。只改路由单元测试及必要的纯逻辑，不启动 lane、Unix socket 或外部 CLI。

验收：`python3 -m unittest discover -s openswarm/tests -p 'test_route.py'`
