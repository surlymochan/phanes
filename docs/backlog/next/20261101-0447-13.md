# OpenSwarm usage：cursor_usage 与 pi_usage 纯单元测试
labels: p2,backend:codex
新建 `openswarm/tests/test_usage.py`，用 `openswarm/tests/_load.py` 的 `load()` 载入 `openswarm/bin/openswarm`，补两个纯函数的单元测试（不启动任何执行器、不联网、不写 ledger）：

① `cursor_usage`（第 4468-4480 行）：入参不是字典时返回四个键都为 0 的字典（键为 `inputTokens`、`outputTokens`、`cacheReadTokens`、`cacheWriteTokens`）；缺字段补 0；字段值是 `None` 或非数字字符串时补 0；正常数字转成 `int`。
② `pi_usage`（第 4677-4708 行）：在临时目录写一个 JSONL 事件文件，文件不存在时返回全 0 的 usage、空的最终文本与空的错误列表；非 JSON 行被跳过；只有 `type == "message_end"` 且 `message.role == "assistant"` 的事件参与统计；多条 assistant 消息的 usage 四个键（`input`、`output`、`cacheRead`、`cacheWrite`）累加；最终文本取最后一条含 `type == "text"` 内容的 assistant 消息；`stopReason == "error"` 或有 `errorMessage` 时错误列表追加错误信息（截断到 500 字符）。

边界：只新建测试文件，不改 `openswarm/bin/openswarm`；不依赖任何其它待办任务。

验收：`python3 openswarm/tests/test_usage.py`
