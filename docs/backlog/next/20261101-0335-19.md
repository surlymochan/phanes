# OpenSwarm retro：失败分类与失败计数的纯单元测试
labels: p2,backend:codex
在 `openswarm/tests/test_retro.py` 增加纯单元测试，覆盖 `openswarm/bin/openswarm` 的 `retro_is_failure`（第 2344-2346 行）、`retro_rejected`（第 2348-2349 行）与 `retro_failure_counts`（第 2327-2342 行）：`exec_pass` 为 False 或 `status` 为 `failed`/`rejected` 算失败；`accepted` 为 False 或 `status` 为 `rejected` 算被拒；失败计数在条目没有 `error_class` 时回落到 `attempts` 里最后一条带 `error_class` 的尝试，两者都没有时不计入；计数按出现次数降序、同次数按名称排序。只用内存条目与现有 ledger fixture，不拉取 knowledge 仓库、不触网、不执行任何命令。

验收：`python3 openswarm/tests/test_retro.py`
