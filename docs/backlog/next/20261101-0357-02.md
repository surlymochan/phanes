# 组织诊断 Boss：--check 校验非对象顶层 JSON 时的结构错误处理
labels: p2,backend:codex
在 `openbot/examples/org-health-local/boss/make_brief.py` 的 `validate_brief`（第 214-225 行）增加顶层类型防卫：入参不是字典对象（如数组 `[]` 或字符串）时，直接返回包含 `任务书必须是 JSON 对象` 的错误说明，避免调用 `brief.get()` 抛出 `AttributeError` traceback；在 `main` 的 `--check` 分支（第 278-285 行）保持退出码 1（`EXIT_INVALID`）。并在 `openbot/examples/org-health-local/boss/test_make_brief.py` 增加 CLI 回归用例：给 `--check` 传入顶层为数组 `[]` 和纯字符串的 JSON 文件，断言退出码为 1、stderr/stdout 提示必须是对象且不出现 `Traceback`。

验收：`python3 openbot/examples/org-health-local/boss/test_make_brief.py`
