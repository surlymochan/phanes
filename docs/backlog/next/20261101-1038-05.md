# 组织诊断 Reviewer：缺少 brief 文件时报告失败原因
labels: p1,backend:codex
在 `openbot/examples/org-health-local/review/cross_check.py` 与 `test_cross_check.py` 增加回归：`--brief` 指向不存在文件时返回非零，错误中包含该路径和“brief”上下文；不要吞掉 `--data` 或 `--dist` 的其它校验结果，也不要改动已有报告格式。

验收：`python3 openbot/examples/org-health-local/review/test_cross_check.py`
