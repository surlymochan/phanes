# 组织诊断 服务：resolve_paths 与路径白名单纯单元测试
labels: p2,backend:codex
在 `openbot/examples/org-health-local/test_serve.py` 增加一个不启 HTTP 服务的纯单元测试类，覆盖 `openbot/examples/org-health-local/serve.py` 的 `resolve_paths`（第 68-71 行）与 `ALLOWED_PATHS`（第 14 行）：

① `resolve_paths()` 无参时返回 `(serve.ROOT, serve.ROOT / 'data' / 'diagnosis.json')`。
② `resolve_paths(root=<临时目录>)` 时，站点根目录是传入的 root，数据文件默认落在 `<root>/data/diagnosis.json`（直接测 `resolve_paths` 这个纯函数，`parse_args` 层的 `--root` 推导已有其它用例覆盖）。
③ `resolve_paths(root, data)` 时以显式传入的 `data` 为准。
④ `resolve_paths(None, data)` 时站点根目录仍是 `serve.ROOT`，数据文件是传入的 `data`。
⑤ `ALLOWED_PATHS` 恰为 `('/', '/index.html', '/app.bundle.js', '/styles.css', '/data/diagnosis.json')` 五项，顺序不变。

边界：只增加单测，不改 `serve.py`；用例不绑定端口、不创建 `ThreadingHTTPServer`、不发起 HTTP 请求。

验收：`python3 openbot/examples/org-health-local/test_serve.py`
