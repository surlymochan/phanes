# 组织诊断 e2e：记录每步耗时缺失字段的失败提示
labels: p1,backend:pi
在 `openbot/examples/org-health-local/run_e2e.py` 与 `test_run_e2e.py` 中补一个回归场景：某一步子进程失败且无法写入 timings 时，命令仍以非零退出，并在 stderr/stdout 中指出失败步骤名称；保持已有成功流水线的 timings JSON 结构与执行顺序不变。只改运行器和对应单测，测试用临时目录及假的角色脚本，不依赖 Bun、网络或真实三 Bot。

验收：`python3 openbot/examples/org-health-local/test_run_e2e.py`
