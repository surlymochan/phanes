# 组织诊断 e2e：上游步骤失败时保留已完成产物与耗时
labels: p1,backend:pi
在 `openbot/examples/org-health-local/run_e2e.py:111-157` 与 `test_run_e2e.py` 增加回归用例：DA 或 Builder 失败后，运行器返回非零，已完成的 `brief.json`/`diagnosis.json` 仍保留，`timings.json` 记录已执行步骤及失败步骤，并继续输出失败步骤名称。不要改变成功路径或审查失败路径的退出码。

验收：`python3 openbot/examples/org-health-local/test_run_e2e.py`
