# 组织诊断 Reviewer：站点缺少 build-report 时可读失败
labels: p2,backend:pi
在 `openbot/examples/org-health-local/review/test_cross_check.py` 覆盖 `run_checks` 未提供 `--dist` 时不生成“站点数据一致”检查项、提供 `--dist` 与数据路径后则生成该检查项。只测可选站点核对的启用条件，不覆盖数据缺失/不匹配的既有用例。依据 `review/cross_check.py:385-417,422-444` 与 `review/test_cross_check.py` 的现有 dist 用例。

验收：`python3 openbot/examples/org-health-local/review/test_cross_check.py`
