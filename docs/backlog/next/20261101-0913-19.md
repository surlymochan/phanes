# OpenSwarm ledger：旧版记录缺少时间字段仍可导出
labels: p2
在 `openswarm/bin/openswarm` 与 `openswarm/tests/test_ledger.py` 增加离线旧版 JSONL 记录夹具，覆盖缺少 created_at、finished_at 或空 metadata 时的读取与 JSON 导出，确认保留核心状态且不生成 traceback。不得访问 GitHub、修改真实 ledger 或改变未知 card type 的既有校验。

验收：`python3 -m unittest discover -s openswarm/tests -p 'test_ledger.py'`
