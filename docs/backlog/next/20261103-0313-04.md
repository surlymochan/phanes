# 诊断输出与输入重合时保留原始数据
labels: p2,backend:pi
修改 `examples/org-health-local/da/build_diagnosis.py` 的 main 与 `examples/org-health-local/da/test_build_diagnosis.py`：当前 --out 与 --brief 相同时，成功生成会用诊断快照覆盖任务书；--out 指向含非法数值的原始 CSV 时，失败清理会删除该输入。生成及失败清理之前核对解析后的输出路径，若与任务书或本次读取的原始 CSV 重合则非零退出，所有输入字节保持不变；覆盖直接相同路径和含 ../ 的等价路径。使用临时目录、非空任务书及四张真实 CSV 调用 CLI，正常独立输出应成功并通过 schema 校验，重合输出分别覆盖原本可成功与原本数据错误两条路径。保留非法数值的既有行列定位、占位文本跳行并记录警告及独立旧快照的失败清理语义。预计实现和回归共 45 行以上，约 30 分钟。

验收：`cd examples/org-health-local && python3 -m unittest da.test_csv_headers da.test_build_diagnosis`
