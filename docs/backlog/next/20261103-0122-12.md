# Builder 站点报告校验文件内容与构建输入绑定
labels: p2,backend:pi
针对真实非空 brief/diagnosis 和静态资源构建站点，报告记录复制资源的 hash/路径；check_site 对未变站点成功，对构建后资源或 JSON 被修改明确失败，再次构建恢复成功。禁止只对空目录做检查。预计有效 diff ≥30 行。 文件：`openbot/examples/org-health-local/builder/build_site.py`、`openbot/examples/org-health-local/builder/test_build_site.py`。

验收：`python3 -m unittest openbot.examples.org_health_local.builder.test_build_site`
