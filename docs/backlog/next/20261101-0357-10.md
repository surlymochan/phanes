# 组织诊断 校验器：--schema 缺失与格式损坏的 CLI 测试
labels: p2,backend:codex
在 `openbot/examples/org-health-local/test_validate.py` 增加 CLI 边界用例：① `--schema` 指向不存在的文件时退出码为 2（`EXIT_USAGE`），stderr 包含「无法读取结构定义」与该路径；② `--schema` 文件为损坏 JSON 时退出码为 2，stderr 包含「不是合法 JSON」；③ `--schema` 顶层为非字典（如 `[]`）时退出码为 2，stderr 提示结构定义必须是对象。确保错误提示清晰且 stdout/stderr 均不包含 Python Traceback。

验收：`python3 openbot/examples/org-health-local/test_validate.py`
