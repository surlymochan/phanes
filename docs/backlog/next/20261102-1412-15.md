# ctl boot 仅在健康心跳失效时重启对应循环
labels: p2

修改 `tools/check-ctl-boot.sh` 与 `tools/start-control-plane` 的可测试启动逻辑，以临时 HOME、伪 pid/heartbeat 和记录型启动器驱动：所有循环健康时不重复启动，单个 heartbeat 过期时只重启对应循环，启动命令失败要在汇总中保留失败且其他健康循环不受影响。用 shell/Python 标准库，不触及用户 ctl 目录或真实进程。预计有效实现+回归 30+ 行，15–40 分钟。依据 `docs/ctl-boot.md` 与 `tools/check-ctl-boot.sh`。

验收：`bash tools/check-ctl-boot.sh`
