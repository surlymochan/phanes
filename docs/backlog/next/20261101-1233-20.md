# OpenSwarm ctl-boot：重启后 bus worker 与 autodispatch 的 pid 状态可恢复
labels: p2,backend:agy
在 `openswarm/bin/hub-openswarm-bridge`、`openswarm/bin/openswarm-auto`、`docs/ctl-boot.md` 对应的现有脚本测试中实现真实重启状态恢复：服务启动前清理过期 pid，启动后记录 bus-worker/autodispatch 的 pid 与启动时间；旧 pid 已退出时不得阻止重启，存活进程不能被重复拉起。用临时 state 目录和 fake worker 命令覆盖一次成功启动与一次 stale pid 清理。

验收：`python3 -m unittest openswarm.tests.test_hub_bridge openswarm.tests.test_autodispatch`
