# 组织诊断 校验器：支持 exclusiveMaximum 关键字
labels: p2,backend:codex
在 `openbot/examples/org-health-local/validate.py` 中扩展对 JSON Schema draft 2020-12 的 `exclusiveMaximum` 关键字支持：① 将 `"exclusiveMaximum"` 加入常量 `SUPPORTED_KEYWORDS` 集合；② 在 `Validator._check`（第 185-195 行附近）中补充校验逻辑：当 schema 中声明 `exclusiveMaximum` 且当前实例为数值类型（int 或 float，排除 bool）时，若 `instance >= schema["exclusiveMaximum"]`，在 errors 列表追加 `f"{pointer(path)}: 数值必须小于 {schema['exclusiveMaximum']}"`；并在 `openbot/examples/org-health-local/test_validate.py` 增加单测覆盖该关键字的通过与失败分支。

验收：`python3 openbot/examples/org-health-local/test_validate.py`
