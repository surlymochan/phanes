# Bus worker 非空任务完成后原子写回结果
labels: p1
在 `openswarm/lib/bus/worker.py` 与 `openswarm/tests/test_github_issue_bus.py` 中实现：补强 worker 从非空任务输入到结果评论的契约：成功执行后结果包含 run id、状态和变更摘要；结果写回中断重试不得产生半截评论或重复 claim。fake gh 驱动完整 worker 路径，成功/失败均覆盖，预计≥30行。 相关契约位于 `openswarm/tests/fixtures/fake_gh.py`。

验收：`python3 -m unittest openswarm.tests.test_github_issue_bus`
