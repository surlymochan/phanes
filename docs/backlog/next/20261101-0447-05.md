# 组织诊断 DA：建议依据里两个数值各自带单位
labels: p2,backend:codex
`openbot/examples/org-health-local/da/build_diagnosis.py` 的 `build_recommendations`（第 853-900 行）中，「核对年末测算与年末目标的口径差异」这条建议的「依据」写成「收入同时给出年末测算 14.8 与年末目标 15.2 万美元/月，口径不同却同屏展示。」——单位「万美元/月」只跟在末项数值后面，前一项数值缺单位，读者容易把 14.8 读成别的单位（`docs/reviews/org-health-data-consistency.md` 的 ISSUE-06）。

改法：把该条建议的「依据」改成两项数值各自带单位，例如「收入同时给出年末测算 14.8 万美元/月 与年末目标 15.2 万美元/月，口径不同却同屏展示。」。

边界：只改这一条建议的「依据」文案，不动该建议的「优先级」「标题」「缺失证据」「验证方式」，不改其它建议、不改快照结构。

在 `openbot/examples/org-health-local/da/test_build_diagnosis.py` 增加用例：跑一次 `build_recommendations`，断言「核对年末测算与年末目标的口径差异」这条建议的「依据」里，「年末测算」与「年末目标」两处数值后面都紧跟「万美元/月」。

验收：`python3 openbot/examples/org-health-local/da/test_build_diagnosis.py`
