# 组织诊断 Reviewer：--help 与必需参数缺失的 CLI 行为测试
labels: p2,backend:codex
在 `openbot/examples/org-health-local/review/test_cross_check.py` 增加 CLI 参数边界测试：① 运行 `python3 review/cross_check.py --help` 退出码为 0，stdout 包含 `--brief`、`--data`、`--dist`、`--out` 参数说明；② 缺少 `--brief` 或缺少 `--data` 时进程以退出码 2 退出；③ 传入合法 brief 与 data 且带 `--out` 时，成功写出 Markdown 报告且内容包含汇总统计与 PASS/FAIL 列表。只用最小 JSON 夹具与临时目录，不改动 `cross_check.py`。
