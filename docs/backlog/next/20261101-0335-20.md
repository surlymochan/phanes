# OpenSwarm lane：lane_call 在 Unix socket 异常时的可读错误
labels: p2,backend:pi
`openswarm/bin/openswarm` 的 `lane_call`（第 6818-6834 行）在连接失败或对端返回非 JSON 时应返回 `{"ok": false, "error": ...}` 而不是抛异常。请在 `openswarm/tests/test_fleet_auto.py` 增加用例（沿用该文件第 298-327 行起的真实 AF_UNIX 夹具）：①让 `lane_socket_path` 指向一个不存在的路径，断言返回 `ok` 为 False、error 含「control socket unavailable」与 errno 文本；②起一个临时 AF_UNIX 监听器并只回一句非 JSON 文本，断言同样返回可读错误，而不是抛 `JSONDecodeError`。只补测试，不改 `lane_call` 的错误文案、重试与派发语义，也不启动真实 lane 或外部执行器。

验收：`python3 openswarm/tests/test_fleet_auto.py`
