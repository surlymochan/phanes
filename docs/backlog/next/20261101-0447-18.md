# OpenSwarm bus：github_repo_from_url 与 gh_pr_number 纯单元测试
labels: p2,backend:codex
在 `openswarm/tests/test_bus.py` 增加针对 `openswarm/bin/openswarm` 的两个纯函数的单元测试（纯函数调用，不发网络请求、不调用 `gh`、不读 ledger）：

① `github_repo_from_url`（第 8918-8927 行）：`https://github.com/owner/repo`、`https://github.com/owner/repo.git`、`git@github.com:owner/repo.git`、`ssh://git@github.com/owner/repo` 都归一化成 `owner/repo`；非 GitHub 域名、缺 owner 或 repo、含非法字符的输入返回 `None`；非字符串入参返回 `None`。
② `gh_pr_number`（第 8953-8959 行）：`{"number": 12}` 返回 12；`{"number": "12"}` 返回 12；`{"number": None}`、缺 `number` 键、`number` 不是数字时返回 `None`；入参不是字典时返回 `None`。

边界：只增加单测，不改 `openswarm/bin/openswarm`；不依赖任何其它待办任务。

验收：`python3 openswarm/tests/test_bus.py`
