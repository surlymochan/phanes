# OpenSwarm lane assign 的非空任务文件生命周期
labels: p1,backend:pi
修改 `openswarm` lane assign/fleet CLI 及相关测试：提交一个非空 task file 后，远端执行前必须确认文件已传输且内容摘要与本地一致；远端拒绝、传输中断或 lane 已占用时不得留下“已分配”假状态，重试同一任务使用稳定 run 标识。基于 `docs/dual-mode-ssh.md:98-121` 的 assign 流程，用现有 fake fleet fixture 覆盖成功、传输校验失败、lane 占用失败三条路径，并断言状态 JSON 可供 autodispatch 消费。

验收：`python3 -m unittest discover -s openswarm/tests -p 'test_lane.py'`
