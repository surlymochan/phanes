# 组织诊断 Reviewer：必答问题为空数组时的失败判定与单测
labels: p2,backend:codex
在 `openbot/examples/org-health-local/review/cross_check.py` 的 `check_questions`（第 395-408 行）中，当任务书 `必答问题` 列表为空（`[]`）时返回 `[Result(False, "必答问题覆盖", "任务书 `必答问题` 为空，没有可核对的问题")]`。请在 `openbot/examples/org-health-local/review/test_cross_check.py` 中补充 CLI 回归用例：构造一个 `必答问题` 为 `[]` 的任务书文件运行 `cross_check.py`，断言退出码为 1（`EXIT_FAIL`），stdout 包含 `FAIL 必答问题覆盖`，且报告汇总中失败数计数增加。只加单测，不改检查器。

验收：`python3 openbot/examples/org-health-local/review/test_cross_check.py`
