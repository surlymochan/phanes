# SSH fleet 证书续签：解析失败不得继续标记健康
labels: p1,backend:agy
在 `swrm/bin/swrm-fleet`、`swrm/bin/fleet-capacity` 和对应 fleet 测试中加入证书状态检查：续签命令成功但输出缺少 expiry 或 expiry 早于当前时间时，主机状态必须为 `certificate_invalid`，不能进入可派发容量；有效证书仍允许非空 lane assignment。用临时 fake ssh 输出有效和过期两种证书，验证 JSON 状态、退出码和容量过滤均一致。

验收：`python3 -m unittest swrm.tests.test_fleet swrm.tests.test_fleet_capacity`
