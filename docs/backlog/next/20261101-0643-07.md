# 组织诊断 validate：JSON 错误显示文件路径
labels: p1,backend:pi
在 `openbot/examples/org-health-local/validate.py` 与 `test_validate.py` 增加损坏 JSON 文件的 CLI 回归用例，断言退出码为 2，stderr 或 JSON 输出包含输入文件路径及解析失败提示；同时覆盖 `--json` 输出仍是合法 JSON。只处理载入错误，不改变 schema 校验错误的既有格式。

验收：`python3 openbot/examples/org-health-local/test_validate.py`
