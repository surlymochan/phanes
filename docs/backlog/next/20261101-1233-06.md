# Issue Bus：无效 result 评论不得结束运行
labels: p1,backend:codex
在 `openswarm/bin/openswarm` 的结果评论读取路径和 `openswarm/tests/test_github_issue_bus.py` 增加字段级校验：`status=ok` 缺少 run_id、`status=error` 缺少非空 error_class、branch 与 run_id 不匹配时，planner 必须继续等待或记录协议失败，而不是写 done/failed 终态。用 fake gh 注入一个损坏评论后再注入合法评论，验证最终只采纳 winning claimer 的合法结果。

验收：`python3 -m unittest openswarm.tests.test_github_issue_bus`
