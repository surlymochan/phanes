labels: p2
修改 `swrm/bin/swrm` 的 bus_worker_run 和 `swrm/tests/test_bus.py`：当前分支 push 成功后 open_pr 抛异常，会落入通用失败报告并丢掉可用 branch/commit。单独处理 PR 创建异常，发布 status=partial、pr_url=null 的 swrm-result，保留真实 branch、commit、files_changed、tests，并在 followups 记录补开 PR 的目标；创建成功时保持 done 与真实 URL。使用 fake gh、临时 bare git 和非空执行产物跑成功与失败路径，验证远端提交存在、planner 能收割 partial 分支且不会重新执行任务。依现有协议由获胜 claim 发布结果，不释放或重领 claim，不引入本地确认存储。预计实现和回归共 45 行以上，约 35 分钟。

验收：`python3 -m unittest discover -s swrm/tests -p 'test_bus.py'`
