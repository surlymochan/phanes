# 组织诊断 DA：问答中增减金额与百分比差值计算
labels: p2,backend:codex
落实 `docs/reviews/org-health-data-consistency.md` 中 ISSUE-03 的审阅意见：在 `openbot/examples/org-health-local/da/build_diagnosis.py` 的 `answer_question`（第 735-748 行）中增强针对成本增减问题的回答能力。当必答问题包含“增减”或“增减多少”时，不只输出期初与期末的绝对值，同时计算差值 `diff = cost['end'] - cost['start']` 与变动百分比 `pct = growth(cost['start'], cost['end'])`，在回答文案中补充「增加/减少 X 万元/月（增幅/降幅 Y%）」；并在 `openbot/examples/org-health-local/da/test_build_diagnosis.py` 补充单测，断言生成的洞察回答中包含计算出的增减数值与百分比。

验收：`python3 openbot/examples/org-health-local/da/test_build_diagnosis.py`
