# DA 原始 CSV 的跨文件期次一致性
labels: p1,backend:pi
修改 `openbot/examples/org-health-local/da/build_diagnosis.py:266-357` 与 `test_build_diagnosis.py`：非空 raw 目录中各业务 CSV 的期次集合必须按 brief 的观察范围形成可解释覆盖；缺少某文件期次时生成可继续使用的缺口事实，重复或超出范围的期次则以文件名/行号报告并失败，不能静默混入指标。使用 `sample-raw` 复制到临时目录并修改两张真实 CSV，覆盖完整成功、单文件缺期但可生成、重复期次失败三条路径，保持 schema v4 输出可校验。
