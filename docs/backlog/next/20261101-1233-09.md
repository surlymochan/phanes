# 组织诊断 Boss：任务书字段类型错误阻止下游运行
labels: p2,backend:codex
在 `openbot/examples/org-health-local/boss/make_brief.py`、`boss/test_make_brief.py` 和 `boss/brief.schema.json` 对非空任务书增加严格契约：观察期间、目标、必答问题等字段类型错误时生成命令必须失败并指出 JSON 路径；合法多期输入仍生成可供 DA 使用的 brief，且不会把字符串拆成字符列表。用临时 JSON 和真实 CLI 覆盖成功与失败退出码。

验收：`python3 openbot/examples/org-health-local/boss/test_make_brief.py`
