# 组织诊断 校验器：多文件校验混合结果与退出码契约测试
labels: p2,backend:codex
`openbot/examples/org-health-local/validate.py` 支持命令行同时传入多个待校验文件。请在 `openbot/examples/org-health-local/test_validate.py` 中增加用例：① 传入两个合格数据文件时退出码为 0，逐个打印校验通过；② 传入一个合格文件与一个不合规文件时退出码为 1，合格文件输出通过、不合规文件输出具体错误路径；③ 同时加 `--json` 参数时，stdout 输出包含全部文件在内的汇总状态与错误列表。只补单测，不改校验器。

验收：`python3 openbot/examples/org-health-local/test_validate.py`
