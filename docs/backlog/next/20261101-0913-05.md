# 组织诊断 DA：带引号逗号的 CSV 字段可稳定读取
labels: p2,backend:pi
在 `openbot/examples/org-health-local/da/build_diagnosis.py` 与 `da/test_build_diagnosis.py` 增加一个 CSV 回归样本：文本字段含引号和逗号时，`csv.DictReader` 路径仍按列名读取数值，生成快照通过现有 schema 校验。边界只覆盖合法 CSV 解析，不改变缺列、重复列和数值错误提示。

验收：`python3 openbot/examples/org-health-local/da/test_build_diagnosis.py`
