# fleet 容量聚合区分部分成功和全失败
labels: p2,backend:agy
在 `openswarm/bin/openswarm-fleet` 与 `openswarm/tests/test_fleet.py` 中实现：多个非空主机响应中单主机超时仍输出其余主机容量及失败 host 详情，全部失败时返回非零并保留结构化结果；真实 fake ssh 调用 CLI 覆盖两路径，预计≥30行。 相关契约位于 `openswarm/bin/fleet-capacity`。

验收：`python3 -m unittest openswarm.tests.test_fleet openswarm.tests.test_fleet_capacity`
