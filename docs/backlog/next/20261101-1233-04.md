# Issue Bus：worker 重启后恢复未完成 claim 的 lease
labels: p1
在 `openswarm/bin/openswarm` 的 bus-worker claim 状态处理和 `openswarm/tests/test_github_issue_bus.py` 增加持久化恢复行为：worker 首次 claim 后在处理前退出，再以同一 name 启动时应复用未过期 claim，并继续该非空任务；过期 lease 才允许另一 worker 接管。测试使用现有 fake gh，断开第一次调用后重启，检查不会创建第二个 run，也不会把原 issue 留在 queued。

验收：`python3 -m unittest openswarm.tests.test_github_issue_bus`
