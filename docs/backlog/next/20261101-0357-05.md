# 组织诊断 DA：write_method.py 输入文件缺失与损坏 JSON 错误处理
labels: p2,backend:codex
`openbot/examples/org-health-local/da/write_method.py` 的 `load_json`（第 31-33 行）直接调用 `path.open()` 和 `json.load()`，当 `--brief` 或 `--data` 文件不存在或不是有效 JSON 时会向外抛出未捕获的 traceback。请修改 `load_json`，捕获 `OSError` 与 `json.JSONDecodeError` 并转化为带文件路径说明的 `MethodError`，由 `main` 统一打印友好错误到 stderr 并以退出码 1 退出；并在 `openbot/examples/org-health-local/da/test_write_method.py` 增加测试：断言 brief 文件缺失及 data 文件损坏时退出码非 0、stderr 包含对应文件名且 stdout/stderr 均不包含 `Traceback`。

验收：`python3 openbot/examples/org-health-local/da/test_write_method.py`
