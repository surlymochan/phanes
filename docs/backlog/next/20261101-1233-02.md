# SSH fleet push：远端已有同名 bundle 时拒绝静默覆盖
labels: p1,backend:codex
在 `openswarm/bin/openswarm-fleet`、`openswarm/bin/fleet-result-bundle` 和 `openswarm/tests/test_fleet_bundle_adapter.py` 修正 push 语义：目标目录已有不同 run id 的 `result.json` 时必须报告冲突并退出，明确 `--replace` 才允许替换；同一 run id 且内容相同的重试保持成功。验收要使用临时目录、两个非空结果文件和真实 CLI，检查冲突不会损坏原 bundle，且幂等重试仍能被 harvest 读取。

验收：`python3 -m unittest openswarm.tests.test_fleet_bundle_adapter`
