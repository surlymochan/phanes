# Review 跨源期间不一致阻止 PASS 并定位字段
labels: p2,backend:codex
用非空 brief、diagnosis 与 dist 数据验证期间一致时 CLI PASS；仅修改 dist 中一个期间或聚合值时输出 FAIL finding，含源路径、字段和两侧值；修复后恢复 PASS。走真实 CLI 与临时目录，不复用单字段缺失用例。预计有效 diff ≥30 行。 文件：`openbot/examples/org-health-local/review/cross_check.py`、`openbot/examples/org-health-local/review/test_cross_check.py`。

验收：`python3 openbot/examples/org-health-local/review/test_cross_check.py`
