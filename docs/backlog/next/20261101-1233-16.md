# OpenSwarm lane：验证失败时结果分支仍保留可审计提交
labels: p2
在 `openswarm/bin/openswarm` 的 verify 失败收尾逻辑、`openswarm/tests/test_lane.py` 和 `openswarm/tests/test_verify_remote.py` 增加非空 lane 回归：agent 已修改文件且 verify 返回非零时，结果必须包含 commit、diffstat、verify_note 和失败命令，branch 可被 fetch；空改动不应伪装成成功提交。使用现有 fake executor 走一次成功修改、一次失败 verify。

验收：`python3 -m unittest openswarm.tests.test_lane openswarm.tests.test_verify_remote`
