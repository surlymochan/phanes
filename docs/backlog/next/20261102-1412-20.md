# Lane 与 bus 对取消信号统一停止并保留终态
labels: p1

在 `openswarm/tests/test_lane.py` 与 `openswarm/tests/test_bus.py` 检查两条执行入口的取消生命周期：运行中收到取消后停止当前子进程且不再领取下一项；已完成的成功结果不被迟到取消覆盖；取消期间 child 退出失败时留下可辨识终态。仅以临时 workspace 和 fake API 边界运行真实子进程管理，不改取消授权规则。预计实现与回归 30+ 有效行，15–40 分钟。依据 `openswarm/docs/BUS.md` Trust and cancellation 与 lane 运行测试。

验收：`python3 -m pytest openswarm/tests/test_lane.py openswarm/tests/test_bus.py -q`
