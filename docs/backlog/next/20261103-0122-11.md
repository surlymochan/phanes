# Boss brief 非空建议输入的结构化校验闭环
labels: p2
为非空的部门目标与建议输入建立端到端校验：合法多条建议生成 schema 合法 brief，字段类型错误或冲突 id 拒绝写入且已有输出保持完整；真实调用 CLI，测试临时源文件，不只断言错误文案。预计有效 diff ≥30 行。 文件：`openbot/examples/org-health-local/boss/make_brief.py`、`openbot/examples/org-health-local/boss/test_make_brief.py`。

验收：`python3 openbot/examples/org-health-local/boss/test_make_brief.py`
