# SSH fleet harvest：远端结果缺失时保留主机级失败证据
labels: p1,backend:pi
在 `openswarm/bin/openswarm-fleet` 与 `openswarm/tests/test_fleet.py` 增加 harvest 的真实失败路径：当一个已分配 lane 返回非零或结果 bundle 缺少 `result.json` 时，命令仍收集其它主机，并为该 host 写入包含 exit code、stderr 尾部和 run id 的结构化失败项。成功 host 的 bundle 不能被失败 host 覆盖，最终 JSON 必须同时区分 `completed` 与 `failed`，并以非零退出码提示部分失败。用临时 fake fleet 和两个非空 bundle 覆盖一成功一失败的端到端调用。

验收：`python3 -m unittest openswarm.tests.test_fleet`
