# 组织诊断 Checker：--help 选项与命令行参数契约单测
labels: p2,backend:codex
在 `openbot/examples/org-health-local/builder/test_check_site.py` 中补充 `check_site.py` 的 CLI 参数契约单测：① 不传任何参数调用时退出码非 0，stderr 提示缺少必选位置参数 `dist`；② 传入 `--help` 时退出码为 0，stdout 包含 `dist` 位置参数说明与用法；③ 传入包含空格的目录路径或相对路径时仍能正常读取并完成检查。只补充单元测试，不修改 `check_site.py` 的检查逻辑与输出格式。

验收：`python3 openbot/examples/org-health-local/builder/test_check_site.py`
