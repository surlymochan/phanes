# SSH push 的批量文件清单与幂等重试
labels: p1,backend:codex
修改 `openswarm` 的 push/结果上传实现及对应测试，使同一 run 含多个非空产物时按明确清单逐项上传，网络中断后只重试未确认项；服务端已存在同内容文件时应报告已确认而非重复破坏目录。失败结果必须带 run、相对路径、已上传数量和下一步提示，成功路径仍返回可消费的状态 JSON。以 `docs/dual-mode-ssh.md:83-130` 的 fleet smoke 作为契约，加入真实临时目录和可控 fake transport 的成功、断连恢复、目标拒绝回归。

验收：`python3 -m unittest discover -s openswarm/tests -p 'test_verify_remote.py'`
