# 组织诊断 Reviewer：--out 输出报告时自动创建父目录
labels: p2,backend:codex
`openbot/examples/org-health-local/review/cross_check.py` 的 `main`（第 490-496 行）在处理 `--out` 参数写出 Markdown 报告时，直接调用 `args.out.write_text()`。当指定的父级目录尚未创建时，会因 `FileNotFoundError` 报错退出。请修改 `cross_check.py`：在写入报告文件前调用 `args.out.parent.mkdir(parents=True, exist_ok=True)`，与 `build_diagnosis.py` 和 `make_brief.py` 保持一致；并在 `openbot/examples/org-health-local/review/test_cross_check.py` 补充用例：传入多层深层未创建目录的 `--out` 路径，断言命令正常执行、返回码为 0 且文件正确写出。

验收：`python3 openbot/examples/org-health-local/review/test_cross_check.py`
