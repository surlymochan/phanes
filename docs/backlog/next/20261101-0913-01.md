# 组织诊断 e2e：审查脚本参数失败时保留审查报告
labels: p1,backend:pi
在 `openbot/examples/org-health-local/run_e2e.py` 与 `test_run_e2e.py` 增加回归用例：`--review` 已执行并由审查脚本写出报告后，审查脚本返回非零时，运行器返回非零且不把流程误报为成功，同时保留 `review.json`。使用临时角色桩和临时报告路径，不改变成功路径的退出码、timings 字段或产物命名。

验收：`python3 openbot/examples/org-health-local/test_run_e2e.py`
