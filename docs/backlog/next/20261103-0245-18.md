# 批处理输入逐项隔离并汇总成功与失败
labels: p1,backend:codex
在 `openswarm/lib/dispatch/batch.py` 与 `openswarm/tests/test_batch.py` 中实现：非空批次中一项执行失败时仍处理后续任务，最终 JSON 对每项记录状态和结果引用，并以非零码标记部分失败；全成功批次仍为零码。使用 fake backend 真实 CLI 测试，预计≥30行。 相关契约位于 `openswarm/bin/openswarm`。

验收：`python3 -m unittest openswarm.tests.test_batch`
