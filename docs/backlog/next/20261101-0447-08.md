# 组织诊断 校验器：组合与数组约束关键字纯单元测试
labels: p2,backend:codex
在 `openbot/examples/org-health-local/test_validate.py` 增加纯单元测试：直接构造小结构定义并调用 `validate.Validator(schema).errors(instance)`（`openbot/examples/org-health-local/validate.py` 的 `_check_choice` 第 246-262 行与 `_check_array` 第 233-244 行），覆盖：

① `allOf`：任一分支不通过即失败，错误信息里带该分支的说明。
② `anyOf`：所有候选分支都不匹配时报「不满足任何一个候选结构」。
③ `oneOf`：匹配的候选结构数量不是 1 个时报「满足的候选结构数量为 N，期望 1 个」（覆盖 0 个与 2 个两种情形）。
④ `prefixItems`：按位置校验前 N 个元素，多出来的元素按 `items` 校验。
⑤ `items` 为 `True` 时不校验元素内容；`items` 为子结构定义时按该结构校验每个元素。

边界：只增加单测，不改 `validate.py` 实现，也不改 `openbot/examples/org-health-local/schema/diagnosis.schema.json`；不依赖任何其它待办任务。

验收：`python3 openbot/examples/org-health-local/test_validate.py`
