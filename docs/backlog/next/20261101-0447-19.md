# OpenSwarm lane：systemd_quote 与 lane_validate_socket_path 纯单元测试
labels: p2,backend:codex
在 `openswarm/tests/test_lane.py` 增加针对 `openswarm/bin/openswarm` 的两个纯函数的单元测试（不起 lane 服务、不创建 Unix socket、不联网）：

① `systemd_quote`（第 8637-8639 行）：普通字符串被双引号包住；`%` 变成 `%%`；`\` 变成 `\\`；`"` 变成 `\"`；含空格与中文的路径同样被正确引用。
② `lane_validate_socket_path`（第 6741-6749 行）：长度正常的 lane 名返回 `lane_socket_path(name)` 给出的 socket 路径；超长 lane 名抛出 `RuntimeError`，信息里含 `AF_UNIX` 与该平台的字节上限（macOS 104、其它 108），并含被拒绝的完整路径；可用 `unittest.mock.patch` 覆盖 `openswarm.lane_socket_path` 来构造超长路径，不必真的建目录。

边界：只增加单测，不改 `openswarm/bin/openswarm`；不依赖任何其它待办任务。

验收：`python3 openswarm/tests/test_lane.py`
