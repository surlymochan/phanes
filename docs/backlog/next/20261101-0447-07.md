# 组织诊断 校验器：数值与字符串约束关键字纯单元测试
labels: p2,backend:codex
在 `openbot/examples/org-health-local/test_validate.py` 增加纯单元测试：直接构造小结构定义并调用 `validate.Validator(schema).errors(instance)`（`openbot/examples/org-health-local/validate.py` 的 `Validator._check` 第 159-208 行），覆盖：

① `minimum` / `maximum` / `exclusiveMinimum`：数值低于下界、高于上界、等于 `exclusiveMinimum` 时报错且错误信息含 JSON Pointer 路径；布尔值不按数值参与比较。
② `minLength` / `maxLength` / `pattern`：字符串长度不足、长度超限、正则不匹配时报错。
③ `enum` / `const`：取值不在允许列表内、与常量不等时报错。
④ `minProperties` / `maxProperties`：对象字段数不足或超出时报错。
⑤ `additionalProperties` 为子结构定义（不是 `False`）时，未声明字段按该子结构校验并给出对应路径。

边界：只增加单测，不改 `validate.py` 实现，也不改 `openbot/examples/org-health-local/schema/diagnosis.schema.json`；`exclusiveMaximum` 关键字由另一条任务单独处理，本任务不覆盖它。

验收：`python3 openbot/examples/org-health-local/test_validate.py`
