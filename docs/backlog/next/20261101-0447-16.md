# OpenSwarm patterns：pattern_next_id 与 pattern_existing_sources 纯单元测试
labels: p2,backend:codex
在 `openswarm/tests/test_patterns.py` 增加针对 `openswarm/bin/openswarm` 的两个纯函数的单元测试（只用临时目录里的本地夹具，不联网）：

边界：只增加单测，不改 `openswarm/bin/openswarm`；与已单独立项的 `parse_pattern_markdown` 前置元数据解析测试无关，不依赖任何其它待办任务。
