# OpenSwarm review：parse_review_by 与 validate_peer_review 纯单元测试
labels: p2,backend:codex
在 `openswarm/tests/test_review.py` 增加针对 `openswarm/bin/openswarm` 的两个纯函数的单元测试（纯内存调用，不启动审查执行器、不联网）：

① `parse_review_by`（第 5548-5556 行）：`"codex"` 返回 `("codex", None)`；`"agy:gpt-5"` 返回 `("agy", "gpt-5")`；未知后端、`"agy:"`（有分隔符但模型为空）、空串都抛 `ValueError`。
② `validate_peer_review`（第 5672-5698 行）：键集合不是 `{findings, verdict}` 时抛 `ValueError`；`findings` 不是列表时抛 `ValueError`；finding 不是对象、缺字段、`severity` 不在 `P0/P1/P2`、`line` 不是正整数（布尔值也不行）、`title`/`body` 不是字符串时都抛 `ValueError`；`verdict` 不是 `approve`/`changes` 时抛 `ValueError`；findings 里出现 P0 或 P1 时返回的 `verdict` 被强制改成 `changes`；合法 payload 返回的 `findings` 里 `path`/`title`/`body` 中的凭据串已被脱敏。

边界：只增加单测，不改 `openswarm/bin/openswarm`；与已单独立项的路由与 retro 统计测试无关，不依赖任何其它待办任务。

验收：`python3 openswarm/tests/test_review.py`
