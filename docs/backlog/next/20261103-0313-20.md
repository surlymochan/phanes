# 独立建站命令限制打包等待时间
labels: p1,backend:codex
修改 `examples/org-health-local/builder/build_site.py` 和 `examples/org-health-local/builder/test_build_site.py`：build_bundle 的 subprocess.run 目前无超时，独立调用建站命令可能无限等待。增加可配置的正数打包超时参数，默认提供有限等待预算；有效 fake bun 成功生成非空 bundle，阻塞 fake bun 超时则终止并等待该进程、返回 EXIT_BUILD，build-failure.json 记录阶段、超时值和命令，正式旧站点保持可用，staging 清理。用真实子进程和短超时跑两条路径，禁止只 mock TimeoutExpired；使用 --bundle 时不启动 bun。不扩展 E2E 进程树清理职责。预计实现和回归共 45 行以上，约 35 分钟。

验收：`cd examples/org-health-local && python3 -m unittest builder.test_build_site`
