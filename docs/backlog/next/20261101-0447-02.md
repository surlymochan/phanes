# 组织诊断 DA：问答回答中补齐收入数值
labels: p1,backend:pi
`openbot/examples/org-health-local/da/build_diagnosis.py` 的 `answer_question`（第 736-772 行）先判 `if "率" in question`，所以必答问题「观察期间的收入是多少（万美元/月）？整体技术人力成本率与营收业务技术人力成本率各是多少？」会落到成本率分支，回答里完全没有收入数值（`docs/reviews/org-health-data-consistency.md` 的 ISSUE-02）。

改法：在含「率」的问题分支里，把收入起止值一并写进回答，例如在三个成本率之前加上「收入 {fmt_number(income['start'])} → {fmt_number(income['end'])} 万美元/月；」。`income` 已由 `build_facts`（第 397-499 行）算好并传入 `answer_question`。

边界：只改「率」分支的回答文案，不改分支顺序、不改「人头」「成本」「收入」与兜底边界分支、不改快照结构与指标数值。

在 `openbot/examples/org-health-local/da/test_build_diagnosis.py` 增加用例：构造一份 `facts`（含 `income`、`ratios`、`overall_cost`、`overall_heads`、`revops_cost`、`revops_heads`）后直接调用 `answer_question`，对同时含「率」与「收入」的问题断言返回内容含收入起止数值与「万美元/月」三个字。

验收：`python3 openbot/examples/org-health-local/da/test_build_diagnosis.py`
