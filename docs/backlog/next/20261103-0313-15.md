# Fleet 状态查询用退出码表达主机不可达
labels: p2,backend:codex
修改 `swrm/bin/swrm` 的 cmd_fleet status 与 `swrm/tests/test_fleet.py`：当前主机探测失败仍正常退出，调用方无法从退出码判断采集不完整。输出所有主机结果后，有 unreachable 或 config invalid 主机时返回非零；正常可达且有非空 lane 的批次成功，明确 paused 的主机保留既有展示与跳过语义。使用 fake host_json 和混合主机配置，验证失败主机不会截断其后健康主机的采集，JSON 和文本两种输出与退出码一致。不涉及证书或 SSH 重试策略。预计有效改动 35 行以上，约 25 分钟。

验收：`python3 -m unittest discover -s swrm/tests -p 'test_fleet.py'`
