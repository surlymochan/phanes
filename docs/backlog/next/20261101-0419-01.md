# 组织诊断 DA：原始数据负数收入校验与错误提示
labels: p1,backend:pi
在 `openbot/examples/org-health-local/da/build_diagnosis.py` 的 `load_raw`（第 330-345 行）中对 `revenue.csv` 与 `forecast.csv` 的收入数值列（`收入万美元`）增加非负数校验：当解析到的数值小于 0 时，抛出 `RawDataError(f"原始数据 {path.name} 第 {number} 行的 {column} 必须是非负数：{number_value}")`；随后在 `openbot/examples/org-health-local/da/test_build_diagnosis.py` 中增加用例 `test_negative_revenue_is_rejected` 与 `test_negative_forecast_revenue_is_rejected`，断言收入列包含负数时进程以非 0 状态码退出，stderr 明确指出文件名与非负数要求，且 stdout/stderr 不包含 Python Traceback。边界：仅增加负数收入校验，保持原有行列解析与空值处理不变。

验收：`python3 openbot/examples/org-health-local/da/test_build_diagnosis.py`
