# 缺陷模式库

此库供铸卡/补池预审与生产 prompt 引用。更新本文件须经 PR 审查；不得绕过审查直接修改模板源。

## 2026-11-02 实测模式

1. **测错对象**：测试未覆盖实际修改的对象或入口。
2. **只覆盖局部却报全局**：局部样本通过即宣称整体正确。
3. **状态读写结构不一致**：写入与读取采用不同字段或数据形状。
4. **dry-run 真执行**：预演模式仍产生实际副作用。
5. **配置优先级写反**：默认值或覆盖配置的优先次序错误。
6. **清理丢任务**：清理流程误删仍需执行的任务。

新卡应在卡面「失败模式清单」中评估并列出适用模式；不适用项可明确标注不适用。
