### Fixed

- Open the app on a database whose own tables are written in a different way. The check that
  protects the tables OpenBot keeps for itself compared the text of every declaration, so a
  database that came from another release of OpenBot was refused when its text differed only in
  spacing or in capital letters. The app did not start then, and the data stayed out of reach. The
  check now compares the declarations the way the tables themselves are built, so that only a real
  difference in columns, checks, keys or indexes stops the upgrade. A reserved table whose name is
  written in capital letters is found and checked as well, so it no longer passes the check
  without its constraints.
