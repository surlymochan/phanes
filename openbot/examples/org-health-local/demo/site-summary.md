## 3. 口径说明（“数据口径”折叠面板 #calibration-panel，共 10 条）

1. 目标：以 2026 H1（2026-05H1参考）为冻结对照基准，复核观察期间内整体技术人力成本与折算人头的水平与变化幅度（合成数据演示）。；说明营收业务（含共享平台）口径的成本、折算人头与收入的匹配情况。；给出整体、营收业务与全口径三个成本率的水平，并解释差异来源。；列明缺少同口径数据的期次与领域，说明缺口对上述结论的影响。。
2. 期间：2026-01 与 2026-09 为已发生实际期次；2026-05 为 H1 参考期次；年末测算与年末目标为测算或目标值。
3. 单位：技术人力成本为万元/月（不含运维与设施）；折算人头为当量折算值，非自然人数；收入为万美元/月；成本率为成本占同期收入按汇率折人民币的比例。
4. 汇率：7.2 人民币/美元；数据截止：2026-09-30。
5. null 含义：表示该期次未统计、未提供或无同口径对比数据，界面显示为未提供，不以 0 或其他推测值替代。
6. 整体技术人力成本 缺 2026-05 数据，按 null 处理
7. 营收业务技术人力成本 缺 2026-05 数据，按 null 处理
