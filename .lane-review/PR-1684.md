   `classify_host_hold` / `review_host_hold`）：
   - 只有正文里写明不可达原因（`ssh` / `unreachable` / `streak`）的 `auto:` 暂停才解除；

     写入时间不再作为解除依据 —— 掉线窗口内写入的独立保护不会被误解除；
   - 手工暂停、`auto:cooldown:`、`auto:host_hard` / `auto:mem_hard` 继续保留；

     issue 的 `in-progress` 标签与 lane 状态保持一致，不会出现「标签还在、lane 记录没了」
     的永久无法重派；
   - `recover_host` 每个 lane 每 tick 只尝试一次重排队（不再先 `reconcile` 再
     `requeue_orphaned_issue` 重复调用）。
3. **移除无关二进制产物**：上一轮 PR 里的 4 个 `openswarm/tests/.*.so` 隐藏二进制
