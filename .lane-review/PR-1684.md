## 6. 已知边界

- 掉线期间**调度器自己**重启过的情况：调度器自己的标记 `auto: host_unreachable` 仍在，
  主机可达时 `host_came_back()` 仍能给出回归边沿（`:607`），所以暂停照样被解除。
- 调度器整个掉线期间由 health-loop 写下、且调度器从未观测到掉线边沿的 `auto: ssh …`
  暂停：仍由 health-loop 自己的 TTL（`QUOTA_HOLD`/`PAUSE_TTL`）解除，本 PR 不缩短它。
- 主机可达但 lane 状态仍是 `busy`（host 侧的陈旧状态）时，卡片会被重新入队；host 侧
  的 lane 状态由 fleet 自己的 supervisor 复位，调度器不会去改 host 的状态文件。
