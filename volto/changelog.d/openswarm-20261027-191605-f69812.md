### Added

- An end-to-end check of the diagnostics export of the account menu. It runs the real export on a
  temporary profile with two agents, three requests and an MCP server, and holds that the report
  counts the agents, the queues, the MCP servers, the browser tabs and the trace spans, that it
  carries the privacy promise, and that it names no conversation, URL, email address, token, file
  path or profile path of the profile it describes.
- An end-to-end check of the ZIP of the backup export on Linux. It puts a fault into the file
  system, a short write and a write that writes no byte, and holds that the export writes the
  whole archive, that it fails instead of reporting a backup that it did not write, and that it
  reads a large file in bounded memory.

### Fixed

- Exporting your data now works on Linux. Before, the export failed there, because it used a tool
  that only macOS has.
- Exporting your data on Linux no longer writes a broken ZIP. The export wrote every chunk of the
  archive once and took the count of the write for the truth, so a short write left a truncated
  archive that the export reported as a saved backup. The export now writes the rest of a chunk
  and fails when a write makes no progress.
- Exporting your data on Linux no longer holds a whole file in the memory of the main process. The
  export read every file whole before it wrote it, so a large file grew the memory of the process
  by its size. The export now reads every file in chunks of a fixed size.
